DINEVIEW AR EVALUATION.

Module: INTE 42312 - Virtual and Augmented Reality | Prepared by: M.A.C.S.S. Jayaweera (IM/2021/100)

1. Project Objectives & Scope

Traditional restaurant menus rely on static text and 2D photographs, which fail to communicate authentic height, spatial volume, presentation, and realistic portion sizes. DineView AR implements a modern, photography-first WebAR preview system enabling customers to inspect dishes as interactive 3D assets and project them at true 1:1 real scale onto physical dining tables or printed Hiro markers.

🎯 Marker-based Tracking

Continuous Hiro marker tracking using A-Frame 1.4.2 and AR.js 3.4.5, anchoring calibrated food models above physical tabletop patterns.

🪑 Markerless WebXR Hit-Test

Horizontal plane detection and surface placement powered by Google <model-viewer> with Scene Viewer and iOS Quick Look fallbacks.

⚙️ Build My Plate Customizer

Multi-step plate configuration modifying portion scales, price multipliers (LKR), and calorie calculations in real time.

5. Dated Technical Challenge & Troubleshooting Log

Date Observed Challenge Root Cause Exact Solution Applied Result
2026-09-02 3D Food floating above detected surface Coordinate origin was centered in 3D volume instead of plate base Set calibrated vertical offsets in menu.json and configured ar-scale="auto" in <model-viewer>. Dishes sit flush on physical table
2026-09-06 Large GLBs (>24MB) causing slow cellular loads High unpruned vertex counts from photogrammetry scan Optimized using @gltf-transform/cli with mesh welding, scene graph flattening, and geometry decimation. 33.9% size reduction & sub-2s loading
2026-09-10 AR.js marker tracking jitter when tilting camera Default AR.js tracking matrix was unsmoothed Configured smooth="true" smoothCount="10" smoothTolerance="0.01" on <a-marker>. Jitter eliminated; steady 60fps tracking
2026-09-18 Portion configuration did not persist across pages Page reloads caused memory state reset Implemented ConfiguratorState singleton with bidirectional localStorage sync and URL query parameter routing. Seamless state continuity across all flows
